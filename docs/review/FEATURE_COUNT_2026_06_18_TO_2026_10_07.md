# Feature Count Audit: June 18–October 7, 2026

## Counted result

The reproducible Git count is **186 uniquely titled feature entries**, represented by **188 non-merge commits** whose subject starts with `feat:` or `feat(`. This is the best auditable count of feature work recorded in the repository over this period.

The count is not a claim of 186 wholly independent, user-facing capabilities. The history has no stable feature IDs: a capability can span several commits, and a single commit can bundle multiple capabilities. The entries also include QA, research, and development tooling alongside Retouch product work.

## Scope and method

- Start: initial commit `641da5befa4b100af00dab13e8ad63e222f159fe`, dated June 18, 2026 at 21:08 MYT.
- End: local `origin/main` at `a692062bfcaa4e69d835a5781e4baa4398b2250b`, dated October 7, 2026 at 11:38 MYT. Local `main` pointed to the same commit when audited.
- Counted non-merge commits reachable from `origin/main`, filtered by the commit subject prefix `feat:` or `feat(`. Feature commits on merged PR branches are included once; merge commits themselves are excluded.
- Of the 188 feature commits, 130 appear on the first-parent history. The period contains 66 pull-request merge commits; this is context only and is not added to the feature count.

The count can be reproduced by listing commit subjects in the date range and counting subjects that begin with `feat:` or `feat(`:

```sh
git log origin/main --no-merges \
  --since='2026-06-18 00:00:00 +08:00' \
  --until='2026-10-08 00:00:00 +08:00' \
  --format='%ad%x09%s' --date=iso-strict
```
